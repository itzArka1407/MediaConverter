# Media Converter

Casual python project to convert formats and codex of images and audio files. I needed this for other purposes - going to the internet again and again was time-wasting and tiring - so made this.

## REQUIREMENTS:
- Needs ffmpeg installed on host system - uses it internally -- check the requirements file which requires ffmpeg

## INSTALLATION:

Load all the dependencies(both dev and prod)

```bash
    pip install -r requirements_dev.txt
```

For getting only the prod dependencies

```bash
    pip install -r requirements.txt
```
